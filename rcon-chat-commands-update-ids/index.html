RCON Chat Commands Update IDs

Update player IDs in your Hell Let Loose RCON chat command configuration.

← Back to Guides

How it works

Paste your complete RCON Chat Commands JSON configuration, choose what to do, then enter the player IDs you want to use.

This tool updates every matching conditions.player_id.player_ids list in the configuration.

Your configuration is processed entirely in your browser. Nothing is uploaded or stored.

1. Paste your current configuration

2. Choose an update type

Enter one ID per line, or separate IDs with commas or spaces. Duplicate entries are ignored.

3. Updated configuration
